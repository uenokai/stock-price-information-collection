# 銘柄発掘システム

このフォルダは GitHub Actions が自動更新する。Obsidian の vault にこのリポジトリを clone し、Obsidian Git プラグインで pull すると、ここが入口のノートになる。

## 見るのはこれだけ

**月に1回、月初の最初の平日の翌日以降に [model-portfolio.md](model-portfolio.md) を開く。**

1. 一番上の「成績」の表で、「対指数」がプラスかを見る
2. 「直近の入れ替え」に出ている買いと売りが、この戦略に従う場合の売買になる。従うなら実行し、従わないなら何もしない
3. 他のファイルは見なくてよい

判断のタイミング: 開始 (2026-10-21) から半年〜1年経った時点で、対指数がマイナスのままなら戦略を見直すか、指数ETFに切り替える。それまでの数字は偶然の影響が大きい。

## 必要なときだけ見る

| 知りたいこと | ファイル |
|---|---|
| 候補銘柄の指標やスコアを見たい | [watchlist.md](watchlist.md) |
| 戦略が過去に指数に勝っていたかを確認したい | [portfolio-backtest.md](portfolio-backtest.md) |
| テクニカル条件が成立した銘柄を見たい | [latest-signals.md](latest-signals.md) |

次の3つは、検証用の記録。見なくてよい。
[performance.md](performance.md) (出したシグナルのその後) / [backtest.md](backtest.md) (シグナルの過去検証) / `signals/` (日次の履歴)

## 現時点の結論 (2026-10-20)

- テクニカルの4シグナルは、全営業日に買った場合と比べて超過リターンが ±1% 以内。買う日を決める根拠にならないので参考情報にした
- 12-1ヶ月モメンタム上位15銘柄の月次保有は、過去約9年で指数ETFとユニバース等金額の両方を上回った (日本 CAGR +24% vs 指数 +12%、米国 +22% vs +15%)。ただし値動きの大きさは約1.5倍になる
- 財務指標による選定は過去時点のデータが無く未検証。週次スナップショット (`../data/fundamentals/`) を蓄積中。モデルポートフォリオの「合成スコア戦略」がその前向き検証を兼ねる

## データの場所

- `../data/watchlist.csv` ウォッチリスト
- `../data/model_portfolio/` ペーパー運用の保有・入れ替え履歴・日次評価額
- `../data/signal_log.csv` シグナル台帳
- `../data/fundamentals/YYYY-MM-DD.csv` 週次の財務指標スナップショット

> 本システムは機械的な判定結果を提示するものであり、投資助言ではありません。
