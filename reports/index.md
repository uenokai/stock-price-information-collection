# 銘柄発掘システム レポート一覧

このフォルダは GitHub Actions が自動更新する。Obsidian の vault にこのリポジトリを clone (または Obsidian Git プラグインで定期 pull) すると、ここが入口のノートになる。

## 見る順番

1. [portfolio-backtest.md](portfolio-backtest.md) **指数に勝てているか** (週次更新)。「対指数」がプラスの戦略だけに意味がある。マイナスなら指数ETFを買う方が良い
2. [watchlist.md](watchlist.md) **今週の候補 60 銘柄** (週次更新)。財務指標 + 12-1ヶ月モメンタムの合成スコア順。前回からの入れ替えも表示
3. [latest-signals.md](latest-signals.md) 候補銘柄のうち今日テクニカル条件が成立した銘柄 (日次更新)。🆕 が新規点灯。参考情報であり売買の引き金ではない
4. [performance.md](performance.md) 実際に出したシグナルのその後 (日次更新)。件数が溜まるまで参考値
5. [backtest.md](backtest.md) シグナルルールを過去5年に当てた成績 (週次更新)。「超過」がゼロ付近 = タイミングの価値なし

## 現時点の結論 (2026-10-20)

- テクニカルの4シグナル (ゴールデンクロス・52週高値・押し目・出来高急増) は、全営業日に買った場合と比べて超過リターン ±1% 以内。買う日を決める根拠にはならない
- 12-1ヶ月モメンタム上位15銘柄の月次保有は、過去約9年で指数ETFとユニバース等金額の両方を上回った (日本 CAGR +24% vs 指数 +12%、米国 +22% vs +15%)。ただし値動きの大きさも増える (年率ボラ 27% vs 18%)
- 財務指標による選定は過去時点のデータが無く未検証。週次スナップショット (`data/fundamentals/`) を蓄積中

## データ

- `../data/watchlist.csv` ウォッチリスト (スコア・指標付き)
- `../data/signal_log.csv` シグナル台帳 (全履歴)
- `../data/fundamentals/YYYY-MM-DD.csv` 週次の財務指標スナップショット (第1段階の検証用に蓄積)
- `signals/YYYY-MM-DD.md` 日次シグナルの履歴

> 本システムは機械的な判定結果を提示するものであり、投資助言ではありません。
